# Interview assessment - Backend

You can ignore this assessment request, if you have already built similar apis or services to demonstrate your coding abilities to employers. If that's the
case, please provide us with the github url (or similar) of your source code.

Estimated time : 3-6 hours (for someone with prior experience on these technologies). We encourage you to time box the assignment and submit the
assignment as is even if you can't complete the assignment by this time. We don't expect working code.

1. Create a spring boot java api that does the following operations
   - Creates a new savings bank account
   - Gets the savings bank account
2. Request Body needs to be validated
3. Account data model:
   1. Account number (Autogenerated by the api)
   2. Id (Autogenerated by the api)
   3. Customer name (input : Mandatory)
   4. Account nick name (input : optional)
4. Account Nick name should be between 5 to 30 characters.
5. A customer cannot create more than 5 accounts.
6. To ensure that the nick name is not offensive, the nick name should be checked against a list of offensive nick names.
7. The bank account details needs to be saved in a postgres database, in a single table.
8. Optional:
   1. Handle error scenarios where the database may be unavailable.
   2. If you are familiar with a caching framework such as Redis, cache the GET calls to the postgres database.
   3. Write any tests that you think would be useful
9. The application should be built using Gradle or Maven.
10. Please feel free to leave TODOs in the source where impractical or time consuming to code features that you would otherwise have coded in a
    real world api.
11. Where requirements appear to be insufficient, assume the requirements based on what you think might be best.

Please provide us the following:

1. Github url containing the source or something similar.

Please do not provide links to source code that could have a commercial value.
